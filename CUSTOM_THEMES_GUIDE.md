# 🎨 Руководство по созданию кастомных тем для Gilvave

В **Gilvave** встроена система пользовательских тем оформления в формате JSON (по аналогии с темами в VS Code). Любой пользователь может создать собственную тему, импортировать её в приложение, отредактировать прямо во встроенном JSON-редакторе или поделиться файлом `.gilvave-theme.json` с сообществом.

---

## 1. Как работает система тем

Весь интерфейс Gilvave построен на **CSS-переменных** (`--color-*`, `--gradient-*`, `--shadow-*`, `--filter-*`). При активации кастомной темы движок (`crates/ui/src/components/common/theme.rs`):
1. Устанавливает базовую тему (`data-theme="advanced"` или `data-theme="standard"`) на корневой элемент `<html>`, чтобы все неуказанные переменные наследовали аккуратные дефолтные значения.
2. Читает упрощённую палитру **`palette`** (до 19 ключевых цветов) и **автоматически генерирует более 120 производных переменных**: полупрозрачные фоны, границы при наведении, свечения (`box-shadow`), градиенты разделителей, бейджи и состояния кнопок с помощью `rgba(...)` и `color-mix(in srgb, ...)`.
3. Поверх сгенерированной палитры применяет точечные переопределения из блока **`variables`** (если автор темы хочет вручную задать конкретный градиент, тень или цвет отдельного элемента).
4. Инжектирует итоговый CSS-блок `:root { ... }` в `<style id="gilvave-custom-theme">` и сохраняет тему в `localStorage` (`gilvave_installed_custom_themes`).

---

## 2. Где управлять темами в приложении

1. Откройте **Настройки профиля** (иконка шестерёнки рядом с вашим профилем в нижней панели).
2. Перейдите во вкладку **«🎨 Внешний вид»**.
3. В разделе **«Управление темами»** доступны кнопки:
   - **«🌐 Каталог тем»** — открывает модальное окно каталога тем сообщества с поиском и установкой в один клик.
   - **«📂 Импорт .json»** — загружает файл `.json` с компьютера.
   - **«✨ Создать / JSON»** — открывает встроенный редактор JSON с предзаполненным шаблоном.
   - **«⬇ Скачать шаблон»** — скачивает готовый файл `gilvave-theme-template.json`.
4. На каждой карточке установленной кастомной темы есть кнопки:
   - **`{ }` (Редактировать JSON)** — открыть исходный код темы в редакторе.
   - **`⬇` (Экспорт)** — сохранить тему в файл `<id>.gilvave-theme.json`.
   - **`✕` (Удалить)** — удалить тему из списка установленных.

## 3. Структура JSON-файла темы

Минимально валидная тема требует только `id`, `name` и хотя бы один цвет в `palette` (или переменную в `variables`). Полная структура выглядит так:

```json
{
  "id": "my-custom-theme",
  "name": "Моя кастомная тема",
  "author": "Ваш никнейм",
  "version": "1.0.0",
  "description": "Краткое описание атмосферы и палитры темы",
  "base": "advanced",
  "palette": {
    "bg_page": "#090a0f",
    "bg_sidebar": "#10121a",
    "bg_channels": "#151824",
    "bg_chat": "#1a1e2d",
    "bg_input": "#121520",
    "bg_modal": "#161a28",
    "bg_message": "#202538",
    "border": "#2a314a",
    "primary": "#6366f1",
    "primary_end": "#8b5cf6",
    "accent": "#22d3ee",
    "accent_warm": "#f59e0b",
    "text_heading": "#f8fafc",
    "text_chat": "#e2e8f0",
    "text_muted": "#94a3b8",
    "text_author": "#a5b4fc",
    "online": "#10b981",
    "idle": "#f59e0b",
    "danger": "#ef4444"
  },
  "variables": {
    "--gradient-date-divider": "linear-gradient(90deg, transparent 0%, rgba(34, 211, 238, 0.4) 50%, transparent 100%)"
  }
}
```

### Поля метаданных

| Поле | Обязательное | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `id` | Да* | Из `name` | Уникальный идентификатор темы (латиница, цифры, `-`, `_`). Не может быть `"standard"` или `"advanced"`. |
| `name` | **Да** | — | Отображаемое название темы в списке и на карточке предпросмотра. |
| `author` | Нет | `"community"` | Никнейм или имя автора темы. |
| `version` | Нет | `"1.0.0"` | Версия темы (например, `"1.0.0"`). |
| `description` | Нет | `""` | Описание темы (отображается на карточке темы и в каталоге). |
| `base` | Нет | `"standard"` | Базовая тема для наследования неуказанных переменных: `"advanced"` (рекомендуется для неоновых/градиентных тем) или `"standard"` (классический спокойный стиль). |

## 4. Справочник палитры (`palette`)

Все поля внутри `palette` опциональны. Рекомендуется указывать цвета в формате HEX (`#rrggbb`), чтобы движок мог автоматически вычислять прозрачность `rgba(r, g, b, alpha)` для теней, рамок и ховер-эффектов.

### Фоны и поверхности

| Ключ в `palette` | Что окрашивает в интерфейсе |
| :--- | :--- |
| `bg_page` | Внешний фон окна приложения (виден в оконном режиме вокруг главной панели), глубокие подложки и скроллбар. |
| `bg_sidebar` | Левая колонка со списком серверов и нижняя панель статуса пользователя (`user-status-bar`). |
| `bg_channels` | Панель списка каналов, навигации личных сообщений и правая панель участников сервера. |
| `bg_chat` | Основная область чата (фон под сообщениями) и шапка активного канала (`chat-header`). |
| `bg_input` | Поле ввода сообщения, строка поиска (`search-bar`), текстовые поля (`input`, `textarea`) в формах. |
| `bg_modal` | Фон модальных окон (настройки профиля, настройки сервера, каталог тем, пикер эмодзи, меню скрепки, развёрнутый редактор). |
| `bg_message` | Фон карточек («пузырей») сообщений в чате и карточек на дашборде. |
| `border` | Базовый цвет разделительных линий, рамок модальных окон, панелей и полей ввода. |

### Акценты и бренд-цвета

| Ключ в `palette` | Что окрашивает в интерфейсе |
| :--- | :--- |
| `primary` | Основной акцентный цвет: кнопки действий, активные табы в настройках, выбранные каналы, ссылки, фокус инпутов. |
| `primary_end` | Второй цвет для градиентов кнопок и активных элементов (`linear-gradient(135deg, primary, primary_end)`). Если не указан, используется `primary`. |
| `accent` | Вторичный яркий акцент (обычно циан/бирюзовый): подсветка иконки активного канала `#`, ховер карточек сообщений, индикатор в строке поиска, счётчик символов в редакторе. |
| `accent_warm` | Тёплый акцент (янтарный/золотой/оранжевый): активный индикатор выбранного сервера слева (`pill`), обводка кнопки главной страницы, плавающий счётчик символов (`>= 4096`), кнопка «Читать далее / Свернуть». |

### Типографика (текст)

| Ключ в `palette` | Что окрашивает в интерфейсе |
| :--- | :--- |
| `text_heading` | Заголовки модальных окон, названия серверов и активных каналов, основной белый текст на кнопках. |
| `text_chat` | Основной текст сообщений в чате, имена участников в списке справа, вводимый текст. |
| `text_muted` | Второстепенный текст: неактивные каналы, плейсхолдеры, подписи форм, время сообщений. |
| `text_author` | Цвет никнеймов авторов сообщений в чате и текста на разделителях дат (`chat-date-divider`). |

### Статусы и системные цвета

| Ключ в `palette` | Что окрашивает в интерфейсе |
| :--- | :--- |
| `online` | Индикатор статуса «В сети», уведомления об успешном сохранении. |
| `idle` | Индикатор статуса «Не активен» / предупреждения. |
| `danger` | Опасные действия (кнопка «Выйти», удаление), ошибки валидации, бейджи непрочитанных сообщений. |

## 5. Продвинутая настройка через `variables`

Если возможностей `palette` недостаточно, вы можете напрямую переопределить любую CSS-переменную приложения в объекте `"variables"`. Значения из `"variables"` применяются **после** `palette` и имеют наивысший приоритет.

### Популярные переменные для переопределения

#### Градиенты (`--gradient-*`)
- `--gradient-bg-body` — фон всего окна за пределами приложения.
- `--gradient-bg-sidebar` — градиент колонки серверов.
- `--gradient-bg-channels` — градиент панели каналов.
- `--gradient-bg-chat` — фоновый градиент области чата (можно задать красивые радиальные свечения `radial-gradient(...)`).
- `--gradient-primary-btn` — градиент основных кнопок.
- `--gradient-primary-btn-hover` — градиент основных кнопок при наведении.
- `--gradient-home-btn` — градиент кнопки «Главная» (домик) в списке серверов.
- `--gradient-hero-banner` — градиент приветственного баннера на главной панели.
- `--gradient-date-divider` — градиент линии разделителя дат в чате.
- `--gradient-server-separator` — градиент разделителя под кнопкой «Главная».
- `--gradient-footer-top-line` — светящаяся линия над нижней панелью профиля пользователя.

#### Цвета отдельных элементов (`--color-*`)
- `--color-bg-message-bubble` — фон пузыря сообщения.
- `--color-bg-message-bubble-hover` — фон пузыря сообщения при наведении курсора.
- `--color-border-bubble` / `--color-border-bubble-hover` — рамка пузыря сообщения.
- `--color-bg-date-badge` — фон плашки с датой (`Сегодня, ...`).
- `--color-text-date-badge` — цвет текста на плашке с датой.
- `--color-bg-chat-input-box` — фон контейнера ввода сообщения.
- `--color-bg-modal-overlay` — затемнение фона вокруг открытых модальных окон.

#### Тени и свечения (`--shadow-*`, `--filter-*`)
- `--shadow-message-bubble` — тень пузыря сообщения.
- `--shadow-primary-btn` — свечение основной кнопки.
- `--shadow-server-icon-active` — свечение вокруг выбранного сервера.
- `--shadow-input-focus` — свечение вокруг поля ввода при фокусе.
- `--filter-pill-active` — `drop-shadow(...)` для полоски активного сервера и канала.

> Полный список всех ~150 переменных можно посмотреть в файле [`crates/ui/src/components/common/_themes.scss`](crates/ui/src/components/common/_themes.scss).

## 6. Правила безопасности и валидации

Чтобы защитить пользователей от CSS-инъекций и поломки интерфейса при установке чужих тем, парсер `CustomTheme::from_json_str` проверяет каждую тему:

1. **Разрешённые префиксы переменных в `variables`**:
   - `--color-*`
   - `--gradient-*`
   - `--shadow-*`
   - `--filter-*`
   - Длина имени переменной — не более `64` символов (только латинские буквы, цифры и дефис `-`). Любые другие ключи игнорируются.
2. **Безопасность значений**:
   - Максимальная длина значения — `400` символов.
   - Запрещены символы `{`, `}`, `;`, `<`, `>`, `\`, а также конструкции `url(`, `expression(`, `javascript:`.
3. **Зарезервированные ID**:
   - Идентификаторы `"standard"` и `"advanced"` зарезервированы за встроенными темами. Если указать их в `id`, движок автоматически сгенерирует безопасный префикс `custom-...`.
